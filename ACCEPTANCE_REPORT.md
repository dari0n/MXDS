## Проверка на чистой Windows 10/11 x64

Отдельной чистой VM в распоряжении цикла не было; приёмка выполнена
на хосте Windows 11 build 26300 в изолированном каталоге. Риски
«грязной» среды минимальны: внешних зависимостей нет, CRT статический,
установка — копирование файлов + опциональная задача Планировщика.
Ручная проверка на чистой VM рекомендуется перед публикацией.

## Найденные и исправленные дефекты цикла

1. PS 5.1 ломал парсинг кириллицы в скриптах без BOM → все скрипты
   дистрибутива принудительно пересохраняются UTF-8 с BOM при сборке.
2. `$var:` в строках PS трактуется как диск → `${var}:`.
3. `verify-install.ps1` не запускался через `powershell -File` без
   параметров: `$PSScriptRoot` в значении параметра по умолчанию
   при `[CmdletBinding()]` в PS 5.1 пуст → резолв в теле скрипта.
4. `install.ps1` не копировал install/uninstall-скрипты, хотя они
   входят в SHA256SUMS → проверка целостности падала; копируется всё.
5. `uninstall.ps1` падал при запуске изнутри удаляемого каталога
   (CWD блокирует удаление) → `Set-Location $env:TEMP` перед удалением.
