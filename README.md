Самостоятельное Windows-приложение на Rust — исследование методов
DPI-фильтрации и поведения сетевых протоколов (TCP/TLS/QUIC) на примере
сервисов Discord и YouTube. Построено на базе открытого проекта
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube):
`winws.exe` и Batch-файлы не используются; оригинальный WinDivert —
только как системный сетевой компонент.

**Платформа:** Windows 10/11 x64 (build 17763+).

## Возможности

- **Сетевой движок на Rust** поверх WinDivert 2.2: fake-пакеты,
  фрагментация, disorder — все DPI-техники оригинала.
- **GUI и CLI** поверх единого ядра: кнопка «Запустить» или `mxds run`.
- **Автоподбор профиля**: при запуске MXDS сам проверяет профили
  каскадом DNS → TCP → TLS → HTTP и выбирает первый рабочий; результат
  запоминается, следующие запуски мгновенные. Отключается в настройках.
- **22 профиля** из оригинального проекта (general, alt-варианты для
  Discord/YouTube) + создание своих через GUI/CLI/копирование .bat.
- **Диагностика с авто-исправлениями**: 19 проверок системы (права, BFE,
  драйвер, TCP timestamps, Secure DNS, конфликтующие службы и т.д.),
  исправимые проблемы закрываются кнопкой «Исправить» сразу с повторной
  проверкой. Из CLI: `mxds diagnostics --fix`.
- **Проверка доступности** Discord/YouTube/Google прямо из приложения.
- **Портабельность**: один exe, статический CRT, внешних зависимостей нет.

## Установка

Дистрибутив — ZIP из раздела Releases (`MXDS-<версия>-win-x64.zip`).

```powershell
# 1. Распаковать ZIP
# 2. Установить (по умолчанию в %LOCALAPPDATA%\Programs\MXDS)
powershell -File install.ps1
#    С автозапуском движка при входе в систему:
powershell -File install.ps1 -Autostart
#    Свой каталог:
powershell -File install.ps1 -InstallDir D:\Tools\MXDS
```

Установка прав администратора не требует; права нужны движку при запуске
(видимый UAC-запрос). При установке проверяется целостность всех файлов
по `SHA256SUMS.txt`; вручную — `verify-install.ps1`.

```powershell
# Удаление (остановка, снятие автозапуска, очистка служб WinDivert):
powershell -File uninstall.ps1
#    С сохранением конфигурации и журналов:
powershell -File uninstall.ps1 -KeepData
```

## Быстрый старт

1. Запустите `mxds.exe` **от имени администратора**.
2. Нажмите **«Запустить»** — автоподбор сам найдёт рабочий профиль
   (первый перебор может занять пару минут, прогресс виден в баннере).
3. Проверьте результат на экране **«Доступность»**.

Если что-то не работает: раздел **«Диагностика»** → «Запустить
диагностику» → кнопки «Исправить» / «Исправить все». Встроенная
инструкция — на экране **«Помощь»**.

## CLI

| Команда | Описание |
|---|---|
| `mxds run [--profile <id>]` | Запустить движок (без `--profile` — автоподбор) |
| `mxds stop` | Остановить движок |
| `mxds status` | Состояние движка и активный профиль |
| `mxds diagnostics [--fix]` | Диагностика; `--fix` — исправить и перепроверить |
| `mxds check` | Проверка доступности целей |
| `mxds profiles list / info / create / mark` | Управление профилями |
| `mxds config show / validate` | Конфигурация |

Коды выхода: 0 — OK, 1 — ошибка, 2 — аргументы, 3 — диагностика FAIL,
4 — нет прав администратора.

## Профили

Профиль — набор стратегий обхода (набор правил движка). 22 профиля
импортированы из оригинального проекта; свои можно создавать:

- GUI: «Профили» → «Создать профиль»;
- CLI: `mxds profiles create <id> --from general`;
- вручную: скопируйте .bat оригинала в `profiles\`.

Подробное руководство: [docs/PROFILE_GUIDE.md](docs/PROFILE_GUIDE.md).

## ⚠️ Безопасность

- **Антивирусы.** WinDivert перехватывает трафик; некоторые антивирусы
  относят его к RiskTool/PUA и могут блокировать. Это известное поведение
  легитимного компонента (так же предупреждает оригинальный проект).
  MXDS никогда не обходит и не отключает антивирус — добавьте папку
  MXDS в исключения.
- **Права администратора.** Загрузка драйвера и управление службами
  требуют прав; запрос всегда виден (UAC), скрытого повышения нет.
- **Целостность.** При каждом старте проверяются SHA256 `WinDivert.dll`
  и `WinDivert64.sys` по эталонным хэшам; при расхождении движок не
  запускается.
- **Никакой скрытой сетевой активности.** Приложение не создаёт серверов
  и не принимает подключений; исходящие запросы — только проверки
  доступности целей из `config/targets.txt`.
- **Логи без содержимого пакетов** — только технические метаданные.
- **Обратимость.** Системные изменения (TCP timestamps, Secure DNS)
  выполняются по кнопке «Исправить» с понятным описанием.

Полный разбор: [docs/SECURITY_REVIEW.md](docs/SECURITY_REVIEW.md).
