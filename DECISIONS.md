# Decisions

Журнал архитектурных и организационных решений MXDS.
Формат: идентификатор, дата, статус, контекст, решение, последствия.

## D-001 — DPI-evasion-техники разрешены к реализации

- Дата: 2026-11-13
- Статус: Accepted
- Контекст: Исходная редакция PROMPT.md (разделы 2.2 и Цикл 7) запрещала
  реализацию техник обхода DPI, что противоречило главной цели проекта —
  функциональному переносу zapret-discord-youtube, чьё ядро (winws.exe)
  целиком построено на десинхронизации DPI (фейковые пакеты, фрагментация
  TLS ClientHello, подмена QUIC Initial и т.д.).
- Решение: Владелец проекта прямым указанием изменил формулировки на
  «Реализовывать…». PROMPT.md отредактирован. Сетевой движок на Rust
  реализует техники обхода DPI, манипуляции пакетами и маскировку сетевого
  поведения, сохраняя приоритет безопасности, целостности соединений и
  отсутствия нарушения штатной сетевой работы.
- Последствия: Цикл 7 включает полный перенос логики десинхронизации;
  .bin-payload-файлы и стратегии оригинала являются функциональными
  требованиями, а не только справочным материалом.

## D-002 — Расположение и имя репозитория

- Дата: 2026-11-13
- Статус: Accepted
- Контекст: PROMPT.md упоминает репозиторий «MXDS», папку «zapret-rust/»
  и CLI-команды «zapret-rust …». Владелец указал создать новый проект
  в C:\Users\MINX\Documents\rust.
- Решение: Корень репозитория — C:\Users\MINX\Documents\rust\MXDS.
  Исходный проект остаётся справочным материалом в
  C:\Users\MINX\Documents\rust\divert\example (только чтение).
  Имя Cargo-пакета и бинарника фиксируется в Цикле 3 (архитектура) —
  кандидат по умолчанию «mxds», при этом соответствие CLI-команд
  из PROMPT.md будет скорректировано и задокументировано.
- Последствия: README и документация используют имя MXDS.

## D-003 — UX-цель и подход к установке

- Дата: 2026-11-13
- Статус: Accepted
- Контекст: PROMPT.md (Цикл 16) требует установщик и удаление, но не задаёт
  формат.
- Решение: Продуктовая цель — «запустил и забыл»: минимум вопросов при
  установке и первом запуске, рабочая конфигурация по умолчанию,
  автоматическая диагностика зависимостей. Формат установщика
  (NSIS / Inno Setup / MSI) выбирается в Цикле 16 по критерию минимальной
  трения для пользователя.
- Выбор формата (Цикл 16, 2026-11-13): **портабельный ZIP +
  PowerShell-скрипты** (scripts/install.ps1, uninstall.ps1,
  verify-install.ps1). NSIS/Inno/MSI отклонены: внешний тулчейн,
  избыточны для single-user локальной утилиты с одним exe. Скрипты
  прозрачны, проверяемы глазами, не требуют ничего сверх Windows.
  Автозапуск «запустил и забыл» — опциональная задача Планировщика
  (install.ps1 -Autostart), а не служба (D-008: единый процесс).
- Последствия: Требования к дефолтной конфигурации и авто-диагностике
  учитываются в Циклах 3–5. Установка без прав администратора
  (в %LOCALAPPDATA%); права нужны только движку при запуске.

## D-004 — Переиспользование данных оригинального проекта

- Дата: 2026-11-13
- Статус: Accepted
- Контекст: PROMPT.md разрешает использовать оригинал как источник
  требований и конфигурационных форматов; статус списков (lists/*.txt)
  и бинарных payload-файлов (bin/*.bin) был не определён.
- Решение: Владелец разрешил использовать неисполняемые данные оригинала
  (списки доменов/IP, .bin-payload'ы) как входные данные для профилей
  стратегий MXDS. Исполняемые компоненты (winws.exe, .bat) по-прежнему
  запрещены к использованию в рантайме.
- Последствия: lists/ и профили стратегий MXDS могут включать данные
  оригинала; лицензия оригинала проверяется в Цикле 1.

## D-006 — bookmark.md: заметки владельца, не ТЗ

- Дата: 2026-11-13
- Статус: Accepted
- Контекст: В рабочей директории появился bookmark.md с альтернативной
  спецификацией v2.0 (кроссплатформа Windows+Linux, другие циклы).
- Решение: Владелец подтвердил, что это его личные заметки: хранить в
  репозитории, но НЕ использовать как источник требований и не читать
  при разработке. Единственное действующее ТЗ — PROMPT.md (Windows-only).
- Последствия: Циклы 2+ выполняются по PROMPT.md. Если владелец решит
  перейти на v2.0, это будет отдельным явным решением с пересмотром
  ROADMAP.md.

## D-005 — Управление Git

- Дата: 2026-11-13
- Статус: Accepted
- Контекст: PROMPT.md требует локальный Git с коммитом на цикл, без push
  и удалённых репозиториев.
- Решение: Владелец делегировал AI-разработчику выполнение git-команд
  (init/add/commit/status/diff) в этом проекте без отдельного
  подтверждения. Push, remote, перезапись истории запрещены.
- Последствия: Один завершённый цикл — один коммит формата
  «cycle(N): описание».

## D-007 — Имя пакета, бинарника, службы и ENV-префикс

- Дата: 2026-11-13
- Статус: Accepted
- Контекст: PROMPT.md использует zapret-rust для папки/CLI, но владелец
  выбрал MXDS как имя проекта и репозитория (D-002).
- Решение: Cargo-пакет и бинарник `mxds`; CLI `mxds <команда>`; служба
  Windows `mxds`; ENV-префикс `MXDS_*` (MXDS_LOG_LEVEL, MXDS_CONFIG_PATH,
  MXDS_DATA_PATH, MXDS_CHECK_UPDATES). Это задокументированное отступление
  от буквы PROMPT.md (Цикл 12 перечисляет zapret-rust …).
- Последствия: команда CLI в документации и справке — mxds.

## D-008 — Модель прав: единый процесс с requireAdministrator

- Дата: 2026-11-13
- Статус: Accepted
- Контекст: Движок требует драйвер (админ); варианты — единый
  elevated-процесс или разделение на непривилегированный UI +
  привилегированный движок.
- Решение: единый процесс, exe-манифест requireAdministrator.
  Обоснование: UX «запустил и забыл» (D-003), отсутствие межпроцессной
  границы доверия, простота жизненного цикла; приложение локальное
  single-user. Диагностика и просмотр конфигурации технически возможны и
  без прав, но единый режим выбран сознательно.
- Последствия: UAC-запрос при каждом запуске exe; служба mxds работает
  под LocalSystem при автозапуске.

## D-009 — Локальная координация: Named Pipe

- Дата: 2026-11-13
- Статус: Accepted
- Контекст: PROMPT.md запрещает HTTP API/WebSocket, требует
  документированный безопасный механизм локальной координации CLI↔GUI.
- Решение: Named Pipe \.\pipe\MXDS.Control, DACL «только текущий
  пользователь», JSON-lines, allowlist команд (status, stop, run,
  get-config, get-logs-tail). Single-instance — мьютекс
  Global\MXDS.SingleInstance + lock-файл с PID.
- Последствия: CLI управляет работающим экземпляром; сетевых сокетов
  приложение не открывает.
